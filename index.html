What I build at Sarcon

Sarcon makes software for in-person, hybrid and virtual events: registration, apps, on-site check-in. I've been there since 2021, starting as an intern.

Agentic AI operations platform

An agent that runs event operations through conversation. Organisers ask in plain language, and it updates speakers, adds conditional registration fields and edits badges. Setup that used to take weeks now takes minutes.

  • 117+ tools, picked per request by vector-based routing
  • Memory across the conversation, plus multi-step reasoning
  • Guardrails: domain-aware tools refuse destructive actions

Claude API, Laravel, PostgreSQL, Redis

  1. Understandintent and context
  2. Routeto the right tools
  3. Actwith guardrails
  4. Observeand self-correct

117tools

Face recognition check-in

Touchless entry in under a second per face. It also tracks zones and sessions, counts meals and giveaways, and catches ticket fraud.

Python, computer vision

Virtual event ecosystem

3D booths, networking and conference tools, so remote attendees can walk the floor and talk to exhibitors.

React, Three.js, WebRTC

Payments and pricing

Integrations with several payment providers, a pricing engine and coupons for ticketing at enterprise scale.
